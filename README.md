## Start

Open [`index.html`](index.html) locally for the interactive, offline research dashboard. Read [`QST-002.md`](QST-002.md) for derivations, physical caveats, and proof obligations.

```bash
python3 -m unittest -v test_qst002.py
python3 base888_bridge.py --tau 8 --p 0.5
```

Python 3.10+ and no third-party packages required. The 888-state finite graph and wave calculations are toy constructions: no nonperturbative quantum gravity, no dynamically emergent Lorentzian spacetime and no chiral Standard Model have been proved.
